# Password Strength Checker

A basic command-line tool written in Python that checks the strength of a password.

## What it checks

- Minimum length (8 characters)
- Uppercase letter
- Lowercase letter
- Number
- Special character

If the password is weak, the tool lists everything it is missing.

## How to run

1. Install Python 3.
2. Run: `python passwordchecker.py`
3. Enter a password when prompted.

## What I learned

- Using `if` statements and lists in Python
- Checking characters with `isupper()`, `islower()`, `isdigit()` and `string.punctuation`
- Basic Git and GitHub workflow
